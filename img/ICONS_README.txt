Icon Files Needed
=================

This extension requires the following icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

Suggested Design:
- Use Inoreader's brand colors or a star icon
- Simple, recognizable design
- Transparent background (PNG format)

Tools for Creating Icons:
- Figma (https://www.figma.com/)
- Canva (https://www.canva.com/)
- GIMP (https://www.gimp.org/)
- Adobe Illustrator/Photoshop

Temporary Solution:
Until proper icons are created, you can use simple colored squares
or find free icon resources from:
- https://www.flaticon.com/
- https://icons8.com/
- https://www.iconfinder.com/

Make sure to check the license for any icons you use!
